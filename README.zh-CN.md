# Pindo 使用说明

Pindo 用于生成和识别拼豆图纸。选择工作模式后上传图片，调整品牌、尺寸、颜色筛选等参数，即可生成带色号标注和用量统计的图纸。

## 工作模式

- 图片生成图纸：适合从照片、插画、像素图生成新图纸。
- 拼豆图纸识别：适合上传已有但没有色号的拼豆图纸，自动补全网格、色号和用量。

## 导出

点击“导出图纸”会下载 PNG 文件。导出的图片包含：

- 带网格的图纸主体
- 每颗拼豆上的品牌色号
- 图纸下方的色号与数量统计

## 本地启动

```powershell
npm install
npm run build
node server.mjs --open
```
